CLEAR DATA PRACTICES

Privacy, in plain language.

This page explains the basic data handled by {{ site_settings.site_name }}.

Account information

When you register, we store your name, email address, a securely hashed password, plan orders, subscription dates and API key records so the service can work.

Site visits

We record page visits, the page path, approximate network address (the final IPv4 segment is masked), referrer path and browser user-agent. This helps the admin understand traffic and improve the website. Admin pages, static assets and API calls are excluded from the visitor page-view list.

Payments

For manual payment verification, we store the payer name, phone number, amount, transaction code and review status. We do not ask for your M-Pesa PIN or one-time password. A payment reference is not automatically proof of payment.

Product data

Product information may include barcodes, names, brands, pack sizes, categories, prices, sources and verification status. A price may vary by retailer and date. Verification labels should not be taken as a guarantee unless an authoritative source has been checked.

Contact and choices

For questions or data correction requests, contact the support address shown on this website when configured. Access credentials should not be shared. API keys can be revoked from your account.

Before public launch, add your legal business details, a working support contact, your retention rules and any additional notices required for your operations.
