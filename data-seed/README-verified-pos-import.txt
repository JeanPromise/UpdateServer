KENYA BARCODE HUB — VERIFIED POS CATALOGUE
Prepared: 2026-10-21
Records: 938 unique barcodes

UPLOAD TO THE WEBSITE
1. Sign in to the website administrator at /promise212324.
2. Open Product catalogue.
3. Under Import catalogue, select verified-pos-products.json.
4. Click Import products. Existing barcodes are updated; new barcodes are added.
5. Check the displayed import counts and search for a few products.

Use verified-pos-products.csv as the alternative import file.

FILE TYPES
- verified-pos-products.json: recommended upload file for Kenya Barcode Hub.
- verified-pos-products.csv: alternative POS-friendly flat file.
- verified-pos-catalogue-only.sqlite3: standalone product-only database for direct SQLite tools. It is NOT a whole-site backup and must NOT be uploaded under Backup & restore.
- source-batches/: source CSV files included for traceability.

VERIFICATION AND PRICES
The site owner instructed that these are the verified POS records. The verified flag reflects the owner's accepted POS status, not an independent GS1 certification. Original source notes are retained. Nine records contain price observations; prices may vary by retailer and date and should be checked before sale.

BACKUPS
Use Admin > Backup & restore for full-site SQLite or full-site JSON backup files. Use that page only with full-site backups downloaded from the website, not the catalogue-only JSON/SQLite files.
